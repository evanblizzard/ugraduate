Retention & Benchmarking: Progress Report

Author

Evan, Natalie, and Myles

1 Topic and Data

1.1 Updates to Context

Initially, our project was based on AU’s static Academic Data Reference Book (ADRB). We have incorporated Professor Ressler’s feedback that the ADRB is “not well-suited for meaningful analysis” due to its single institution scope and inconsistent table structures.

1.2 Updates to Problem

Thus, we have pivoted the context from a just AU point-of-view to a multi-institutional one. The problem is now: “How does university student success (retention) compare to peer institutions when controlled for cost, financial aid profiles, and program specialization?” We are now utilizing the U.S. Department of Education’s IPEDS database because of its comprehensive longitudinal data.

1.3 Updates to Use Case

Our primary actors of administrators and secondary actors of students remains the same. However, their use cases have expanded.

  • Institutional Peer Bench Marking: Administrators are no longer limited to internal department trends. Ideally, they will be able to identify a set of “peer schools” using Euclidean distance to see if their institution’s retention gaps among Pell Grant recipients vs non-recipients are unique or reflect broad trends.

  • Program Strength: Users can now analyze Program Strength relative to other schools by examining HHI scores.

1.4 Updates to Data Sources

IPEDS data is now the source for our app.

1.4.1 Variable Overview:

Currently, our variables include the following:

1.4.1.1 Institutional Identifiers/Characteristics

  • unitid: A unique identification number assigned to every postsecondary institution.

  • instnm: The official name of the institution.

  • stabbr: The state abbreviation for where the institution is located.

  • Control: Classification of the institution (Public, Private nonprofit, Private for-profit)

1.4.1.2 Retention and Student Success:

  • ret_pres: The percentage of first-time, full-time degree-seeking undergrads from the previous fall who are enrolled again in the current fall

  • pell_pct: The same statistic as above, but for Pell Grant recipients

  • net_price_avg: The average net price for students receiving regular forms of aid (loans, scholarship, etc.)

  • net_price_pell_avg: There was no variable specifically for the average net price for Pell recipients, so the average net price for students on 0-30k income was used as a proxy.

  • hhi_score: Calculated value representing program concentration of universities. Sum of the squares of the shares of each CIP code’s enrollment.

    • Number of students in a specific 2-digit CIP code / total number of students at university

      • Then squared and summed.

3 Update of App Design

3.1 Options for User Data Selection

  • Sector Selection: A selectInput that lets users filter the IPEDS dataset by type of institution

  • State Filtering: A multi-select menu to subset institution type by state

  • School Filtering: A searchable menu that to add specific schools that fall under the above filters.

  • Metric selection: Lets users select between overall retention rate, pell retention rate, and average net price.

  • We would like a “Find My Peers” button that performs the Euclidean distance calculation between the selected school and the rest of the filtered dataset.

    • Not yet implemented

3.2 Options for Exploratory Numerical and Graphical Analysis

  • Current functionality:
    • Institutional Retention Trends: Interactive plotly line charts that plot either retention rate, pell retention rate, or HHI over time for selected institutions.
    • Programmatic Specialization (HHI) Scatter Plot: A visualization that displays the HHI scores against retention rates.
      • Currently, there appears to be very little correlation, so this feature would likely be improved if users could scatter whichever variables they like.
  • Ideal Functionality:
    • Data Tables: Filterable tables to show raw numerical values for retention, net price, HHI, and potentially admission
      • We would have to add admission data to the current master_data file
    • Retention Gap Analysis: A grouped bar chart comparing Overall Retention vs. Pell Student Retention
    • Selectivity vs Outcome Modeling: A scatterplot with a regression comparing admission to retention
      • This could be incorporated into the current HHI Scatter tab.
    • Euclidean Distance: A plot representing Euclidean distance of peer schools.
      • Could use a cluster plot

5 Risk Assessment

The only major problem run into so far is problems with data ingestion. Some variables are named differently across different years and are located in different tables. This was able to be resolved with some light LLM usage to help review the exhaustive codebooks, but if more variables need to be added, this could be a bit of a time sink.
